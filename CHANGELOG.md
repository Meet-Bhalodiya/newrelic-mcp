# Changelog

All notable changes are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-06-30

### Added

- Greenfield TypeScript MCP server with stdio and stateless Streamable HTTP.
- Typed NerdGraph client, bounded NRQL wrappers, safety gates, and dry-run writes.
- Read-only resources, workflow prompts, runtime diagnostics, and metrics.
- npm, container, Helm, MCP Registry, and MCPB packaging metadata.
- Unit, contract, integration, security, load, and opt-in live test scaffolding.

### Security

- Read-only defaults, account allowlists, origin and host validation, bounded
  responses, secret redaction, and bearer/OIDC HTTP authentication.
