# Support

Please use the channel that matches your need so maintainers can help quickly and
sensitive data stays out of public view.

## Questions and usage help

Start with the documentation:

- [README](README.md) — requirements, quick starts, and client setup
- [Configuration reference](docs/configuration.md)
- [Client configuration](docs/client-configuration.md)
- [Troubleshooting](docs/troubleshooting.md)

Never include New Relic keys, bearer tokens, JWTs, account IDs, NRQL, entity
details, or raw responses in any public channel.

## Bugs and feature requests

Open an issue with the [bug report or feature request template](https://github.com/Meet-Bhalodiya/newrelic-mcp/issues/new/choose).
Blank issues are disabled, so please choose a template.

## Security vulnerabilities

Do not open a public issue. Follow [SECURITY.md](SECURITY.md), which uses GitHub's
private vulnerability reporting.

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md) for development setup and the pull request
process.
